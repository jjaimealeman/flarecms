# Requirements: Flare CMS -- Live Demo

**Defined:** 2026-03-16
**Core Value:** Let visitors experience FlareCMS firsthand with zero friction -- email in, demo out.

## v2.1 Requirements

### Demo Access

- [x] **DEMO-01**: Visitor enters email on /demo page and receives OTP code via Resend
- [x] **DEMO-02**: Visitor enters OTP code and is logged into admin as `demo` role
- [x] **DEMO-03**: Demo user session expires after 30 minutes
- [x] **DEMO-04**: Demo signup captured in `demo_signups` table (email, IP, timestamp)

### Sandbox

- [x] **SAND-01**: `demo-sandbox` collection exists with sample fields (title, content, status)
- [x] **SAND-02**: Demo role has read-only access to all collections except sandbox
- [x] **SAND-03**: Demo role has full CRUD on `demo-sandbox` collection only
- [x] **SAND-04**: Demo users limited to 50 mutations per session
- [x] **SAND-05**: Demo file uploads restricted to images only, max 2MB

### Demo Page

- [x] **PAGE-01**: `/demo` Astro page with brief explanation and email input
- [x] **PAGE-02**: Disclaimer about data reset and session limits displayed on page
- [x] **PAGE-03**: After OTP verification, redirect to admin.flarecms.dev with demo session

### Reset & Cleanup

- [x] **RESET-01**: Cron trigger runs every 6 hours
- [x] **RESET-02**: Cron deletes all demo-sandbox content and re-seeds with clean data
- [x] **RESET-03**: Cron purges expired demo user sessions

**packages/cms/src/index.ts:**
1. Add `DemoResetService` to the import from `@flare-cms/core`:
   ```typescript

   ```

2. Update the `scheduled()` handler to dispatch on `controller.cron`:
   ```typescript
   async scheduled(controller: ScheduledController, env: any, ctx: ExecutionContext) {
     if (controller.cron === '0 */6 * * *') {
       const service = new DemoResetService(env.DB, env.CACHE_KV)
       ctx.waitUntil(service.run())
     } else {
       const scheduler = new SchedulerService(env.DB, env, ctx)
       ctx.waitUntil(scheduler.processScheduledContent())
     }
   },
   ```

The `else` branch preserves the existing every-minute content scheduler for all other cron expressions. The `controller.cron` string MUST match the wrangler.toml expression exactly (`'0 */6 * * *'`).

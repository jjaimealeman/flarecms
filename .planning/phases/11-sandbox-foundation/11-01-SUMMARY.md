## Decisions Made

- Migration SQL lives in `packages/core/migrations/` (not `src/db/migrations/`) — the pre-commit hook runs `generate-migrations.ts` which scans that directory and auto-bundles all SQL into `migrations-bundle.ts`. Manually editing `migrations-bundle.ts` is overwritten by the hook.
- Seed content `author_id` uses `admin-1770148233567-90a7ju7xz` (the known local admin ID) — D1 FK constraints require a real user ID; 'system' as a literal would fail.
- The plugin has no API routes in Phase 11. Routes come in Plan 02 / Phase 12. The import in `app.ts` ensures the module is bundled now so Phase 12 can add routes without another app.ts change.
